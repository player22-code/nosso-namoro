NOSSA HISTÓRIA — PACOTE COMPLETO EM UMA SÓ PASTA

1. Extraia o ZIP no computador ou celular.
2. Envie o index.html e TODOS os demais arquivos extraídos para a RAIZ do repositório nosso-namoro. Não envie apenas o ZIP ao GitHub: o site não lê arquivos dentro de um ZIP.
3. Substitua o index.html anterior quando o GitHub pedir. Preserve os nomes dos arquivos, maiúsculas, minúsculas, espaços e extensões.
4. Imagens, GIFs, PNG, JPEG, WebP, WebM e áudios ficam na mesma pasta do index.html. Não crie subpastas para esses arquivos. Não é necessário apagar as pastas antigas existentes no repositório.
5. O CSS e o JavaScript dos cassinos já estão embutidos no index.html. Não é necessário enviar cassinos.css nem cassinos.js deste pacote.
6. Após a publicação, recarregue a página para atualizar o cache.

O ZIP inclui o index.html COMPLETO do site, os recursos de mídia existentes no repositório e a referência enviada. As fotos, histórias, músicas, chat, planos e os demais controles foram mantidos. Os caminhos locais foram ajustados para uma só pasta; arquivos com nomes repetidos e conteúdo diferente receberam um nome único. O MAPA_DOS_ARQUIVOS.json registra cada caminho anterior e seu nome neste pacote.

O pacote é para o repositório existente; NÃO configura um novo Supabase. Login, histórias e moedas continuam usando o Supabase já configurado no site e exigem internet e uma sessão autorizada. O navegador não cria créditos reais na carteira. Os testes da carteira utilizam respostas simuladas; crédito real no Supabase ainda requer validação autenticada.

Os cassinos aparecem na aba Jogos, após entrar no site e escolher Modo Solo ou uma história do casal. Há uma entrada para cada tema. No computador, aparecem lado a lado; no celular, use os seletores de tema. GIRAR, +/−, Auto de até 10 giros, sons, música, saldo e fechar são controles reais.

Não foram fornecidos os ZIPs antigos de outra conversa. Os recursos disponíveis no repositório e a imagem enviada foram aproveitados.
